# Diagnóstico Microlab

Diagnóstico y definición estratégica de marca para Microlab (rebranding de los 20 años), preparado por Wasabi.

Incluye: diagnóstico de situación, públicos y stakeholders, mapa competitivo, rol de marca, valores, plataforma de marca, territorio de identidad visual, conceptos creativos y pilares de comunicación.

## Publicar con GitHub Pages
1. Settings → Pages → Branch: `main` / carpeta `/ (root)`.
2. El sitio queda en `https://[usuario].github.io/Microlab/`.

Basado en el brief de proyecto (mayo 2025) y la minuta de reunión de alineamiento.
